    YouTube API key

    Search needs a free YouTube Data API v3 key (direct paste-and-play works without one). Get one in about 2 minutes:

    1. Go to console.cloud.google.com and sign in
    2. Create a new project (any name)
    3. Search "YouTube Data API v3" → Enable
    4. APIs & Services → Credentials → Create Credentials → API key
    5. Paste it below. It's saved only in this browser (localStorage).
